# Mount Rushmore of OOP

Four principles built everything you use. Encapsulation, Abstraction, Inheritance and Polymorphism as four monuments carved into a 3D Mount Rushmore. Click a face and warp into its world.

Built with Three.js, GSAP (ScrollTrigger, SplitText, MorphSVG), Lenis and Vite. All sound is synthesised live with the Web Audio API.

## Run

```sh
npm install
npm run dev
```

Pushing to `main` deploys to GitHub Pages through `.github/workflows/deploy.yml`.
